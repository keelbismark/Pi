# Pi

Небольшая веб-страница с описанием в репозитории GitHub — «Infinity Pi Generator». Продуктовая часть не документирована: назначение генератора, способ синхронизации между пользователями и роль счётчика онлайн нигде не описаны, а собранные файлы не образуют работающей страницы. Ниже — только то, что фактически есть в коде.

## Возможности

Что действительно реализовано в коде:

- Фоновая анимация «цифрового дождя» на `<canvas id="matrix-bg">`: колонки из символов `0`, `1`, `ПЂ` падают вниз, скорость пересчёта 35 мс, холст перестраивается при изменении размера окна.
- Генератор `generatePi()` — поразрядное вычисление цифр π генератором на целых `BigInt` (`function*`), выдающий цифры по одной.
- Вывод цифр по одному в `#pi-display` с добавлением класса `new-digit` и снятием его через 600 мс; прокрутка списка к низу.
- Счётчик сгенерированных цифр в `#digit-count`.
- Управление выдачей: пауза/продолжение (`#pause-btn`), ускорение и замедление шагом 50 мс (`#speed-up`, `#speed-down`), сброс с очисткой вывода и счётчика (`#reset-btn`). Интервал ограничен диапазоном 50–2000 мс.
- Начальное состояние: константа 200 мс, генератор прокручивается на одну цифру перед стартом, чтобы в первой выдаче не было ведущей тройки.

Чего в коде нет:

- Счётчик пользователей онлайн: в разметке есть только `<span id="user-count">?</span>`, значение никогда не заполняется и не вычисляется.
- Firebase: в `index.html` есть только комментарии-заглушки «Firebase SDK» и «Конфигурацию Firebase нужно будет вставить»; кода интеграции нет.
- Сам генератор страницы: `index.html` подключает `<script src="script.js">`, но файла `script.js` в репозитории нет.

Обратите внимание: `server.js` не подключён в `index.html` и обращается к элементам (`#pi-display`, `#digit-count`, `#pause-btn`, `#speed-up`, `#speed-down`, `#reset-btn`), которых в разметке нет, — в `index.html` присутствуют только `#number-display`, `#user-count` и классы `.stats`/`.info`. То есть в текущем виде страница показывает статичный текст и пустые счётчики, а генератор цифр к ней не подключён.

## Стек

- JavaScript (ES2020 — `BigInt`, генераторы `function*`), HTML5, CSS3.
- Canvas API для фоновой анимации, шрифт Roboto Mono с Google Fonts.
- Внешних зависимостей нет: файлов `package.json`, манифеста сборки и системы сборки в репозитории нет.
- Размещение — GitHub Pages: в корне лежит `CNAME` с доменом.

## Установка и запуск

Сборки нет, установка зависимостей не требуется. Файлы статические, их достаточно положить в любой каталог веб-сервера:

```bash
git clone https://github.com/keelbismark/Pi.git
cd Pi
python -m http.server 8000
```

После этого страница будет доступна на `http://localhost:8000`. Файл `index.html` можно открыть и напрямую в браузере.

Для публикации на GitHub Pages достаточно включить Pages для ветки `main` с корнем репозитория; домен берётся из файла `CNAME`.

## Структура проекта

- `index.html` — страница: canvas фона, заголовок, блок `#number-display` со значением «3.», поясняющий текст, счётчик `#user-count`, комментарии-заглушки под Firebase и подключение отсутствующего `script.js`.
- `style.css` — оформление: цветовая схема на CSS-переменных, `#number-display`, `.digit` и `.new-digit`, анимации `fadeIn` и `pulse`, фон `#matrix-bg`, медиазапрос для ширины до 768 px.
- `server.js` — несмотря на имя это клиентский скрипт: фоновая анимация на canvas и генератор цифр π с управлением выдачей. Серверной части в репозитории нет.
- `CNAME` — домен для GitHub Pages: `3.141592653589793238462643383279502884197169399375105820974944592.pro`.

Других файлов нет.

## Переменные окружения

Переменные окружения не используются: файлов `.env` и `.env.example` в репозитории нет, конфигурация Firebase, судя по комментариям, должна была вставляться в разметку вручную.
